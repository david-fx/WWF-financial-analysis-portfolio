# WWF FY2024 Sustainable Finance & Impact Efficiency Case Study

## 📌 Project Overview
This repository contains a comprehensive financial analysis and portfolio project for a non-profit organization. The project focuses on evaluating the sustainable finance, financial health, and operational impact efficiency of **WWF, Inc. and Subsidiaries** based on their Consolidated Financial Statements for FY2024 and FY2023.

*   **Prepared by:** David FX Winata
*   **Date:** March 6, 2025
*   **Purpose:** Portfolio project for NGO Financial Analysis

## 📁 Repository Contents
This repository includes three main files:
1.  **`David_FW_WWF_FY2024.xlsx`** – The financial model containing raw data processing, horizontal (YoY) variance analysis, financial ratio calculations, and the KPI dashboard.
2.  **`David_FW_WWF_FY2024.pptx`** – The presentation slide deck summarizing the financial position, operational performance, and strategic insights.
3.  **`David_FW_WWF_FY2024.pdf`** – The final exported PDF version of the presentation for easy viewing without requiring PowerPoint.

## 📊 Key Insights & Takeaways
Based on the FY2024 financial data, the analysis reveals:
*   **Robust Financial Health:** The organization maintains excellent liquidity (Current Ratio of **3.92**) and virtually zero leverage risk (Debt Ratio of **17.8%**).
*   **High Operational Efficiency:** An impressive **84.2%** of total operating expenses are allocated directly to mission-driven program services (Conservation & Public Education).
*   **Fund Structure Challenge:** While Net Assets grew by a healthy **10.1%** (Unrestricted), **64%** of total funds remain restricted. This highlights the need for strict cash flow management for operational overhead.
